## What it does

<!-- Stable description of the program. Carried forward from the previous note; edit only when the product itself changes.
     3 to 6 lines: what it is, who uses it, where it runs (URL/port/binary), how to start it. -->
A TOML 1.1 parser written in pure Mojo. It passes the complete official
conformance suite, [toml-test](https://github.com/toml-lang/toml-test) v2.2.0:
**214/214 valid and 467/467 invalid** documents, on Mojo 1.2.0 and on the 1.2 nightly.

```mojo
from toml import parse

def main() raises:
    var doc = parse(open("config.toml", "r").read())
    var server = doc["server"]
    print(server["host"].as_string(), server["port"].as_int())
```
