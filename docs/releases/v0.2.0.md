# mojo-toml v0.2.0

**Released:** 2026-10-21 · **Commit:** `1e1edaa` (public) · **Previous:** first release

## What it does

A TOML 1.1 parser written in pure Mojo. It passes the complete official
conformance suite, [toml-test](https://github.com/toml-lang/toml-test) v2.2.0:
**214/214 valid and 467/467 invalid** documents, on Mojo 1.1.0 and on the 1.2 nightly.

```mojo
from toml import parse

def main() raises:
    var doc = parse(open("config.toml", "r").read())
    var server = doc["server"]
    print(server["host"].as_string(), server["port"].as_int())
```

## Highlights

- Full TOML 1.1: every case in the official suite parses or is rejected as the spec says.
- Every TOML type: all string kinds and escapes, integers in four bases, floats, booleans,
  the four datetime kinds, arrays, tables, inline tables, arrays of tables, dotted keys.
- Typed accessors that raise on a type mismatch, and errors that name the position:
  `toml: duplicate key 'a' at line 2:6`.
- Fast on large files: a 3.1 MB document with 20,000 tables parses in 104 ms.
- Pure Mojo, installs with the `mojo` package alone. Docs in `docs/`, and a skill file for
  coding agents in `skills/mojo-toml/SKILL.md`. Apache-2.0.

## Known limits

- Parse only, no TOML writer. `to_json` is the toml-test debug format.
- Datetimes are returned as text plus a kind, not date objects.
- No strict TOML 1.0 mode: the 1.1 additions are always accepted, so 9 TOML 1.0 "invalid" tests parse.
- No Mojo package registry yet: install from source, a precompiled `.mojoc`, or by vendoring.
