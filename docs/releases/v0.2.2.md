## What it does

A TOML 1.1 parser written in pure Mojo. It passes the complete official
conformance suite, [toml-test](https://github.com/toml-lang/toml-test) v2.2.0:
**214/214 valid and 467/467 invalid** documents, on Mojo 1.2.0 and on the 1.2 nightly.

```mojo
from toml import parse

def main() raises:
    var doc = parse(open("config.toml", "r").read())
    var server = doc["server"]
    print(server["host"].as_string(), server["port"].as_int())
```

## Highlights

- Integer tokens are parsed from a view with no copy and no digit list, so parsing is faster.
- `parse` is smoke-tested against random input: it raises, it never crashes.

## Changes

### Added
- `recipe.yaml`: a conda package recipe.
- A property smoke step in the gate: `parse` never crashes.
- `mojo-upgrade` config.
- CI, latest-release and license badges in the README.
### Changed
- Integer tokens are parsed from a view, no copy and no digit list.
- README: one install and quickstart block, one example.
### Fixed
- Integers outside the signed 64-bit range are rejected.
- Array and inline-table nesting is bounded at 128 levels.
- Seconds are not inserted before a fraction: `07:32.5` is invalid.
